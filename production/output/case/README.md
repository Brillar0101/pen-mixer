# Case print files

Two clear shells exported from `production/blender/pen-mixer.blend` in
millimetres, ready to upload for 3D printing (PRD P2).

| File | Size (mm) | Holds |
|------|-----------|-------|
| `case_bottom.stl` | 15.40 x 39.60 x 6.05 | board and battery, USB-C notch |
| `case_top.stl` | 15.40 x 39.59 x 2.35 | covers the components, slot for the side button |

Order notes (from the PRD): JLCPCB 3D printing, 8001 clear resin, no
supports needed for either half, print with the open face down. The halves
hold by wall friction plus the USB-C notch keying them together; if the
printed fit is loose, snap ridges are the fallback. The LEDs shine through
the clear resin. Not yet printed; ordering closes P2.
